# Iamthevali.github.io

Starter portfolio site for Iamthevali. Replace placeholder content in `index.html` and update avatar, links, and projects.

To deploy locally:
1. Create repository named `Iamthevali.github.io` in your GitHub account (owner: valithesky).
2. Copy these files into the repo, preserving the `assets/` folder.
3. Push to the default branch (usually `main`) and GitHub Pages will publish automatically for a user site.

Example git commands:
```bash
git init
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin https://github.com/valithesky/Iamthevali.github.io.git
git push -u origin main
```
